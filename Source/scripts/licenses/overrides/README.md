# Licence texts for crates that publish none

A few crates name a licence in Cargo.toml but leave the licence file out of the published package. `build-notices.mjs`
uses `<crate name>.txt` from this folder for them. Take each text from the crate's own repository and note it here.

| File | Taken from | Checked |
| --- | --- | --- |
| `webview2-com.txt`, `webview2-com-sys.txt` | https://github.com/wravery/webview2-rs/blob/main/LICENSE (MIT, "Copyright (c) 2021 Bill Avery") | 2026-10-23, copyright line to be confirmed against the repository by the owner |
