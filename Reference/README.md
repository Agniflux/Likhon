# Design files the builds read

A copy of four files from the maintainers' design folder, so this repository builds on its own:

- `design-tokens.json`: the colours (light and dark) for the Settings window, the native windows and the installer.
- `design-v2/icons.js`: the duotone icon set (icons are exported from it at build time; an unknown name is a build error).
- `design-v2/assets/likhon-mark.svg`: the quill mark (installer art, icons).
- `design-v2/assets/likhon-icon.svg`: the app icon, the white quill on a rounded square in the brand blue (`#2747C4`); the same file is the website's icon. Used by the README.
- `design-v2/assets/splash.png`: the splash picture.

Do not edit them here: they are snapshots of the design source of truth.
