3. What Likhon does on your computer

So that you know what you are agreeing to:

- Typing. To turn your keystrokes into Bangla, Likhon reads them while it is switched on, either through a
  keyboard hook (Portable) or as a Windows text service (installed with the keyboard-list option). What you type is
  processed on your computer only. It is never sent anywhere and never written to a log.
- On macOS and Linux. Likhon is an input method. The system sends it your keystrokes while you type in a text box
  where it is switched on, and it turns them into Bangla on your computer only. On Linux it keeps its settings and the
  words it learns in files in your home folder (~/.config/likhon/ and ~/.local/share/likhon/) that you can read and
  delete. The macOS version does not keep any files of yours yet.
- Learning words. Likhon can remember words you type so it can suggest them later. They are kept in a file on
  your computer. It never learns from fields that Windows reports as password fields, and you can see, export
  or delete these words in Settings.
- Where it writes. Likhon keeps its files in a folder beside likhon.exe (or in your user profile if that
  folder is read-only). It writes to the Windows registry only for what you switch on: Start with Windows and fonts
  you install (for your Windows account), and adding Likhon to the Windows keyboard list (which asks for
  administrator permission once). The installer adds only what you choose on its feature page: the text service and
  its registration, a Start with Windows entry, fonts, shortcuts and its uninstall entry.
- Restoring the Windows Bangla font. Likhon no longer changes which font Windows uses for Bangla. If an earlier
  version changed it, Settings › Fonts can put Windows' own setting back; this asks for administrator permission.
- The internet. Likhon connects to the internet only when you ask it to: to check for updates, open or download
  from the library, download the dictionary, or donate words. There is no telemetry and no background connection. What these
  requests send is described in the Privacy notice.
